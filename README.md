# 数独 模様帖 (sudoku_web_2)

`sudoku_web` の改良版。`index.html` をブラウザで開くだけで動きます（file:// 可、ビルド不要）。

## 変わったところ

- **模様生成**
  - 対称でそろえる: 点対称 / 90°回転 / 左右・上下鏡映 / 対角・逆対角鏡映 / 上下左右 / 両対角 / 全対称 / なし。
    対称な組（軌道）ごとにまとめて抜くので、ヒント配置は必ず厳密に対称になります。
  - 図形を描く: ハート・花・ねこ・雪の結晶など 16 種。ヒントの位置を図形に**ぴったり**固定し、
    「解の個数が減る向き」に数字を入れ替える局所探索で一意解になる割り当てを探します。
    「さらに削る」を選ぶと旧 EXTREME と同じく図形の内側も最小まで間引きます。
- **難易度** は人の手筋で判定: やさしい(隠れシングル) / ふつう(＋裸のシングル) /
  むずかしい(ポインティング・ボックスライン・ペア) / 達人(トリプル・X-Wing・XY-Wing・ソードフィッシュ・クアッド) /
  鬼(それでも解けない)。
- **ソルバ** はビット演算 + MRV。一意性判定は 1 回あたりミリ秒未満〜数ミリ秒。
- 生成は Web Worker（Blob 経由）で行い、画面は固まりません。途中でやめられます。
- 画面: 昼は方眼ノート、夜は黒板。活字＝ヒント、手書き＝自分の記入。メモ、同じ数字の強調、
  重複の朱表示、答え合わせ、手筋名つきヒント、候補の一括メモ、戻す/やり直す、一時停止、自動保存。

## ファイル

- `engine.js` — ソルバ・採点器・生成器（ブラウザ / Worker / Node 共通）
- `app.js`, `style.css`, `index.html` — 画面
- `test/verify.js` — `node test/verify.js [回数] [予算ms]` で一意解・難易度・対称性・生成時間を実測
